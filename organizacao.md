# Organização e Divisão de Tarefas

## Problema
- [ ] Definir contexto do sistema
- [ ] Identificar principais atores
- [ ] Definir 6-10 requisitos funcionais
- [ ] Identificar restrições relevantes
- [ ] Selecionar e descrever 3 ASRs (com justificativa)

## Domínio

- [ ] Definir classes/conceitos do domínio
- [ ] Definir responsabilidades
- [ ] Justificar com GRASP ou SOLID e analisar coesão e acoplamento

## Modelagem

- [ ] Diagrama de classes
- [ ] Diagrama de Sequência
- [ ] Diagrama de Comunicação
- [ ] Diagrama de Componentes ou Pacotes

> Uma opção interessante é usarmos o Mermaid para criar os diagramas, é uma linguagem simples de marcação que dá para anexar em markdown
> Ou usamos o PlantUML sugerido pela prof

## Proposta Arquitetural

Nesta etapa é interessante discutirmos em grupo qual será a arquitetura que mais encaixa no problema.

- [ ] Principais componentes e módulos (responsabilidades)
- [ ] Organização arquitetural explícita (como ela aparece na solução)
- [ ] Pelo menos duas alternativas arquiteturais além da solução proposta
- [ ] Apresentar trade-offs
- [ ] ADR 1
- [ ] ADR 2
- [ ] ADR 3

- [ ] Definir linguagem e tecnologias
- [ ] Implementação
